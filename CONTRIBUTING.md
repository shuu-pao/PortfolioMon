# Contributing Guidelines

## Code of Conduct
- Follow project-wide code style rules (Eslint configured)
- All PRs require testing (Jest tests must pass)

## Workflow
1. Fork repository
2. Create feature branch (`git checkout -b feature/your-feature`)
3. Submit PR with descriptive title
4.await review from project maintainers

## Technical Details
- Pre-commit hooks enforced (Eslint, Prettier)
- Dependencies versioned in `package-lock.json`
